# ML Encrypto Project

Учебный pet-проект для автоматического взлома шифра простой моноалфавитной замены на русском и английском языках.

Программа обучает символьную n-граммную языковую модель на Википедии, строит начальный ключ по частотам букв и улучшает его методом имитации отжига.

## Возможности

- русский и английский алфавиты;
- отдельный корпус Википедии для каждого языка;
- шифрование и расшифрование по известному ключу;
- автоматический поиск неизвестного ключа;
- частотная инициализация ключа;
- символьная 3-граммная языковая модель;
- несколько независимых запусков имитации отжига;
- терминальный ввод многострочного шифртекста;
- вывод расшифровки, ключа, оценки модели и времени работы;
- автоматические тесты основных компонентов.

## Как работает проект

```text
Выбор языка
    ↓
Загрузка соответствующего корпуса
    ↓
Обучение 3-граммной модели
    ↓
Шифртекст
    ↓
Начальный ключ по частотам букв
    ↓
Перестановка двух букв ключа
    ↓
Пробная расшифровка
    ↓
Оценка языковой моделью
    ↓
Имитация отжига
    ↓
Лучший найденный текст и ключ
```

Языковая модель выступает функцией оценки: чем естественнее выглядит текст, тем выше его средняя логарифмическая вероятность.

Имитация отжига всегда принимает улучшения и иногда принимает ухудшения. Это позволяет выходить из локальных максимумов и исследовать разные варианты ключа. По мере уменьшения температуры вероятность принятия плохих вариантов снижается.

## Контрольные результаты

На отдельных контролируемых примерах длиной около 350 букв получены следующие результаты:


Это результаты отдельных экспериментов, а не средние метрики по полноценному тестовому набору.

## Требования

- Python 3.10 или новее;
- подключение к интернету для первоначального скачивания корпусов.

Проект разрабатывался и проверялся на Python 3.13.

## Установка

```bash
git clone https://github.com/Tim2la/ML_Encrypto_project.git
cd ML_Encrypto_project
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Подготовка корпусов

Скачать русский корпус:

```bash
python download_corpus.py --language ru
```

Скачать английский корпус:

```bash
python download_corpus.py --language en
```

Скачать оба корпуса:

```bash
python download_corpus.py --language all
```

По умолчанию для каждого языка загружается около 10 миллионов символов. Размер можно изменить:

```bash
python download_corpus.py --language en --target-characters 1000000
```

После загрузки появятся файлы:

```text
data/wikipedia_ru.txt
data/wikipedia_en.txt
```

## Запуск программы

Основной запуск выполняется только через `main.py`:

```bash
python main.py
```

Программа предложит выбрать язык:

```text
Выберите язык шифртекста:
1 — Русский
2 — English
```

После обучения модели вставьте шифртекст. Для завершения ввода отправьте пустую строку.

Программа выведет:

- исходный шифртекст;
- найденную расшифровку;
- оценку языковой модели;
- время работы;
- соответствия зашифрованных и обычных букв.

## Запуск тестов

```bash
python -m pytest -v
```

## Ограничения

- поддерживается только простая моноалфавитная замена;
- пробелы и знаки препинания предполагаются незашифрованными;
- короткие тексты расшифровываются хуже длинных;
- качество зависит от корпуса и параметров поиска;
- редкие буквы могут восстанавливаться неправильно;
- модель обучается заново при каждом запуске;
- найденный вариант не гарантирует точного восстановления исходного текста.

Для устойчивого результата рекомендуется использовать не менее 200–300 букв.

## План развития

- провести оценку качества на большом наборе текстов;
- измерить среднюю точность восстановления текста и ключа;
- сохранять обученные модели между запусками;
- показывать прогресс расшифрования;
- улучшить обработку редких букв;
- добавить чтение и запись Excel-файлов;
- создать веб-интерфейс.

## Цель проекта

Цель проекта — изучить Python, автоматическое тестирование, статистические языковые модели и методы комбинаторной оптимизации на практической задаче криптоанализа.

Проект является учебным и не предназначен для взлома современных криптографических алгоритмов.
