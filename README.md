# ML Encrypto Project

Учебный pet-проект для автоматического взлома шифра простой моноалфавитной замены с помощью символьной языковой модели и алгоритма имитации отжига.

Пользователь вводит неизвестный шифртекст, после чего программа ищет вероятный ключ замены и выводит найденную расшифровку.

## Возможности

Текущая версия проекта умеет:

- генерировать случайный ключ простой замены;
- шифровать текст по заданному ключу;
- расшифровывать текст по известному ключу;
- проверять корректность ключа;
- нормализовать русский текст;
- обучать символьную n-граммную модель;
- оценивать, насколько текст похож на русский язык;
- строить начальный ключ с помощью частотного анализа;
- искать ключ методом имитации отжига;
- выполнять несколько независимых перезапусков поиска;
- принимать неизвестный шифртекст через терминал;
- выводить шифртекст, найденную расшифровку, ключ, оценку модели и время работы;
- автоматически тестировать основные компоненты проекта.

## Как работает проект

Общий процесс расшифрования:

```text
Шифртекст
    ↓
Нормализация текста
    ↓
Частотный анализ
    ↓
Начальный ключ
    ↓
Изменение ключа
    ↓
Пробная расшифровка
    ↓
Оценка языковой моделью
    ↓
Имитация отжига
    ↓
Лучший найденный текст и ключ
```

Проект состоит из двух основных частей:

1. Языковая модель оценивает, насколько результат похож на русский текст.
2. Алгоритм имитации отжига ищет ключ с наиболее высокой оценкой.

## Языковая модель

Проект использует символьную 3-граммную языковую модель.

Например, текст:

```text
КРИПТО
```

разбивается на триграммы:

```text
КРИ
РИП
ИПТ
ПТО
```

Для каждой триграммы модель определяет контекст и следующий символ.

Например, для триграммы:

```text
КРИ
```

контекстом будет:

```text
КР
```

а следующим символом:

```text
И
```

Модель обучается на корпусе русской Википедии и подсчитывает:

- количество каждой триграммы;
- количество каждого контекста;
- вероятность следующего символа после контекста.

Используется аддитивное сглаживание:

```text
P(символ | контекст) =
(количество триграммы + alpha)
/
(количество контекста + alpha × размер алфавита)
```

Сглаживание не позволяет неизвестным последовательностям получить нулевую вероятность.

Для оценки текста используется средняя логарифмическая вероятность. Чем выше оценка и чем ближе она к нулю, тем естественнее текст с точки зрения модели.

Например:

```text
-2.2 лучше, чем -3.4
```

Оценка модели не является процентом точности.

## Имитация отжига

Для русского алфавита существует `33!` возможных ключей простой замены, поэтому полный перебор невозможен.

Алгоритм имитации отжига:

1. Получает начальный ключ, построенный по частотам букв.
2. Выбирает две буквы ключа.
3. Меняет их значения местами.
4. Расшифровывает текст изменённым ключом.
5. Оценивает результат языковой моделью.
6. Всегда принимает улучшения.
7. Иногда принимает ухудшения, чтобы не застрять в локальном максимуме.
8. Постепенно уменьшает температуру и вероятность принятия плохих решений.
9. Возвращает лучший ключ, найденный за всё время.

Вероятность принятия ухудшения вычисляется по формуле:

```text
P = exp(
    (candidate_score - current_score)
    /
    temperature
)
```

В начале алгоритм активнее исследует разные ключи. По мере уменьшения температуры поиск становится более строгим и принимает почти только улучшения.

Для повышения устойчивости выполняется несколько независимых запусков отжига. После этого выбирается результат с максимальной оценкой языковой модели.

## Результат текущего эксперимента

На контролируемом русском тексте длиной около 300 символов программа получила:

```text
Точность расшифровки: 99.25%
Время работы: около 6 секунд
```

Модель правильно восстановила почти весь текст, но в двух местах перепутала редкие буквы `Ж` и `Ё`.

Это результат одного контролируемого эксперимента, а не средняя метрика по полноценному тестовому набору.

## Структура проекта

```text
ML_Encrypto_project/
├── data/
│   └── wikipedia_ru.txt
├── src/
│   ├── __init__.py
│   ├── cipher.py
│   ├── ngram_model.py
│   ├── solver.py
│   └── text_processing.py
├── tests/
│   ├── test_cipher.py
│   ├── test_ngram_model.py
│   ├── test_solver.py
│   └── test_text_processing.py
├── .gitignore
├── download_corpus.py
├── main.py
├── README.md
└── requirements.txt
```

Назначение файлов:

- `main.py` — основной запуск терминальной программы;
- `download_corpus.py` — скачивание корпуса русской Википедии;
- `src/cipher.py` — шифрование, расшифрование и работа с ключами;
- `src/text_processing.py` — нормализация текста;
- `src/ngram_model.py` — символьная n-граммная языковая модель;
- `src/solver.py` — частотный анализ и поиск ключа методом имитации отжига;
- `tests/` — автоматические тесты;
- `requirements.txt` — зависимости проекта.

Файл `data/wikipedia_ru.txt` создаётся после запуска загрузчика и не хранится в Git.

## Требования

- Python 3.10 или новее;
- подключение к интернету для первоначального скачивания корпуса.

Проект разрабатывался и проверялся на Python 3.13.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Tim2la/ML_Encrypto_project.git
cd ML_Encrypto_project
```

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Активировать окружение на macOS или Linux:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

## Подготовка корпуса

Перед первым запуском необходимо скачать обучающий корпус:

```bash
python download_corpus.py
```

После завершения появится файл:

```text
data/wikipedia_ru.txt
```

Корпус содержит примерно один миллион символов русской Википедии.

Загрузка корпуса выполняется только один раз. При последующих запусках повторно скачивать его не нужно.

## Запуск программы

Основная программа запускается через `main.py`:

```bash
python main.py
```

После запуска программа обучит языковую модель и покажет приглашение:

```text
Вставьте шифртекст.
После последней строки нажмите Enter ещё раз:
```

Вставьте шифртекст. После его последней строки отправьте пустую строку.

Программа выведет:

- исходный шифртекст;
- найденную расшифровку;
- оценку языковой модели;
- время работы;
- найденные соответствия зашифрованных и обычных букв.

## Запуск тестов

Все тесты запускаются командой:

```bash
python -m pytest -v
```

## Ограничения

- текущая версия поддерживает только русский алфавит;
- программа предназначена только для шифра простой моноалфавитной замены;
- короткие тексты расшифровываются хуже длинных;
- качество зависит от размера и содержания обучающего корпуса;
- редкие буквы могут восстанавливаться неправильно;
- модель обучается заново при каждом запуске;
- результат зависит от параметров поиска;
- найденный вариант не гарантирует точного восстановления исходного текста;
- предполагается, что пробелы и знаки препинания не зашифрованы.

Для более устойчивой расшифровки рекомендуется использовать тексты длиной не менее 200–300 букв.
