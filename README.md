# ML Encrypto Project

Учебный pet-проект для автоматического расшифрования текстов, зашифрованных методом простой замены.

## Возможности

На текущем этапе проект умеет:

- генерировать случайный ключ замены;
- шифровать русский текст;
- расшифровывать текст с известным ключом;
- проверять корректность ключа;
- сохранять пробелы и знаки препинания;
- автоматически тестировать основные функции.

## Установка

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Активировать окружение на macOS или Linux:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск программы

```bash
python src/cipher.py
```

## Запуск тестов

```bash
python -m pytest -v
```

## План развития

В следующих версиях планируется:

- построить символьную языковую модель;
- оценивать правдоподобность расшифрованного текста;
- искать ключ с помощью алгоритма simulated annealing;
- добавить поддержку английского языка;
- добавить загрузку Excel-файлов;
- создать пользовательский веб-интерфейс.

## Цель проекта

Изучить Python, основы разработки и применение методов машинного обучения для решения задачи криптоанализа.
