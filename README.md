# ML Encrypto Project

Учебный pet-проект для автоматического взлома шифра простой моноалфавитной замены на русском и английском языках.

Программа использует символьную 3-граммную языковую модель для оценки вариантов расшифровки. Поиск ключа начинается с частотного анализа и продолжается методом имитации отжига.

## Возможности

- работа с русским и английским алфавитами;
- обучение языковых моделей на отдельных корпусах Википедии;
- сохранение обученных моделей для следующих запусков;
- шифрование и расшифрование по известному ключу;
- автоматический поиск неизвестного ключа;
- несколько независимых запусков поиска;
- ввод многострочного шифртекста в терминале;
- вывод расшифровки, найденного ключа, оценки модели и времени работы;
- автоматические тесты основных компонентов.

## Как это работает

Подготовка выполняется один раз для каждого корпуса:

```text
Корпус Википедии
       ↓
Очистка текста
       ↓
Обучение 3-граммной модели
       ↓
Сохранение модели в папку models/
```

При обычном запуске:

```text
Выбор языка
       ↓
Загрузка готовой модели
       ↓
Ввод шифртекста
       ↓
Начальный ключ по частотам букв
       ↓
Изменение ключа и пробная расшифровка
       ↓
Оценка текста языковой моделью
       ↓
Имитация отжига и несколько запусков поиска
       ↓
Лучший найденный текст и ключ
```

Языковая модель вычисляет среднюю логарифмическую вероятность текста: более естественные сочетания символов обычно получают более высокую оценку.

Имитация отжига принимает улучшения и иногда допускает ухудшения. Это помогает поиску выходить из локальных максимумов. По мере снижения температуры вероятность принять ухудшение уменьшается.

## Требования

- Python 3.10 или новее;
- интернет для первоначального скачивания корпусов.

Проект разрабатывался и проверялся на Python 3.13.

## Установка

```bash
git clone https://github.com/Tim2la/ML_Encrypto_project.git
cd ML_Encrypto_project
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Подготовка данных

Скачать оба корпуса:

```bash
python download_corpus.py --language all
```

Можно скачать только один язык:

```bash
python download_corpus.py --language ru
python download_corpus.py --language en
```

По умолчанию для каждого языка собирается около 10 миллионов символов. Размер можно изменить:

```bash
python download_corpus.py --language en --target-characters 1000000
```

После скачивания файлы появятся в папке `data/`.

## Обучение моделей

После скачивания корпусов обучите обе модели:

```bash
python train_models.py
```

Скрипт сохранит результаты в `models/ru_model.pkl` и `models/en_model.pkl`. Обучение нужно повторять только при изменении корпусов или параметров модели.

## Запуск расшифровки

```bash
python main.py
```

Программа предложит выбрать язык:

```text
Выберите язык шифртекста:
1 — Русский
2 — English
```

После загрузки модели вставьте шифртекст. Чтобы закончить ввод, отправьте пустую строку.

Программа покажет исходный шифртекст, найденную расшифровку, ключ замены, оценку модели и время поиска.

## Тесты

```bash
python -m pytest -q
```

На текущем этапе проходят 29 тестов.

## Результаты и ограничения

На отдельных контролируемых примерах длиной около 350 букв удавалось восстановить 100% букв на русском и английском языках. Это результаты отдельных запусков, а не средняя точность на большом тестовом наборе.

- Поддерживается только шифр простой моноалфавитной замены.
- Пробелы и знаки препинания предполагаются незашифрованными.
- Короткие тексты обычно расшифровываются хуже длинных.
- Качество зависит от корпуса и параметров поиска.
- Редкие буквы могут восстанавливаться неправильно.
- Лучший найденный вариант не гарантирует точного совпадения с исходным текстом.

Для более устойчивого результата рекомендуется использовать шифртекст длиной не менее 200–300 букв.

## План развития

- оценить качество на наборе текстов разной длины;
- измерить точность, долю полностью расшифрованных текстов и время работы;
- сравнить настройки языковой модели и алгоритма поиска;
- создать API для расшифровки;
- подключить Telegram-бота;
- при необходимости добавить MCP-инструмент для AI-агентов.

## Цель проекта

Проект помогает на практике изучить Python, тестирование, статистические языковые модели и методы комбинаторной оптимизации на задаче криптоанализа.

Проект учебный и не предназначен для взлома современных криптографических алгоритмов.
